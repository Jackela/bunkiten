# 协议常量单一真源 shared/protocol.mjs（RULES 除外）

协议常量此前双侧各一份、只靠契约 lint 比对两份源码文本：客户端 `src/lib/parser.ts` 持 `PROTOCOL_HEADS`/`AUDIO_KINDS`，服务端 `server/acp-server.mjs` 持 `AUDIO_EXTS`/`AUDIO_FILE_RE`/`AUDIO_REL_RE`/`AUDIO_MIME` 与自己的 `AUDIO_KINDS`；更糟的是 `pickEffort`（推理分档）与 `isMainTurn`（正戏回合判定）各持一份手写指令前缀正则（`^(规划：|美术：|…)`），lint 完全没管它们——本次核实两份集合恰好相同、仅交替顺序不同，但任何一侧单改就会让档位与快照语义静默分叉。裁决：新建零依赖纯常量模块 `shared/protocol.mjs` 收编 `PROTOCOL_HEADS`、`AUDIO_KINDS`/`AUDIO_EXTS`/`AUDIO_MIME`/`AUDIO_FILE_RE`/`AUDIO_REL_RE`（保持「后两者由前两者构造」的形态）与 `DIRECTIVE_PREFIX_RE`（统一 pickEffort/isMainTurn 的两份等价副本；「待命：」是开局指令的后缀判定、不属前缀集合，「开局：」「继续世界：」属 isDirectivePrompt 的世界落盘嗅探、刻意不收——开局/续玩无待命后缀时是正戏回合，收进来会改变快照与档位语义）。`src/lib/parser.ts` 改为 import + re-export（公共 API 逐字不变，store/测试仍从 `src/lib/parser` 与 `store/game` import），`server/acp-server.mjs` import 消费并 re-export `AUDIO_KINDS`/`AUDIO_EXTS` 保住 doctor.mjs 的既有 import 面；TS 侧配手写 `shared/protocol.d.mts`（tsconfig 是 `module: ESNext` + `moduleResolution: bundler`，`.mjs` 按 `.d.mts` 解析；vite/vitest/electron 直接吃 .mjs），仅 `PROTOCOL_HEADS`/`AUDIO_KINDS` 用字面元组承接 `AudioKind` 的字面联合与原 `as const` 语义，扩展名白名单刻意不在声明里重复第二份字面。契约 lint 同批从「双侧比对」改「真源断言」：①⑤组的目标文件换成 shared（源码字面 + import 值 + parser re-export 链三方钉住，并断言 server 不再自持 `AUDIO_EXTS`/`AUDIO_MIME` 声明），新增⑥组钉 `DIRECTIVE_PREFIX_RE`（pickEffort/isMainTurn 函数体都引用它、server 源码无第二份前缀字面）与主题白名单（server `FONT_PRESETS`/`DIALOG_TEXTURES`/`DEFAULT_THEME` ↔ `src/theme.ts` 的 `FONT_PRESETS`/`DIALOG_TEXTURES`/`FALLBACK_THEME` 同集同值——两份兜底 accent2 出生即分叉 `#e8e4da`/`#e7d5ae`，取 server 值对齐：`normalizeTheme` 在 `/api/presets` 出口填的兜底值就是玩家实际看到的默认色，改客户端为零可见行为变化，顺手同步 `global.css` 的 CSS 初始 `--accent2`）。**RULES 刻意不收编**：它是 server 常量 ↔ `.grok/skills/bunkiten/SKILL.md` 的逐字副本，而引擎（grok agent）只读 `.grok/` 提示词文件、不会 import 代码，双份天然必须存在，lint 逐字比对仍是正确机制。代价：其一，打包布局多一条规则（electron-builder `files: shared/**`，server 经相对路径 import，缺了打包态起不来）；其二，`.d.mts` 的字面元组是类型层镜像，改协议头要动两处（.mjs 值 + .d.mts 类型），运行时真源仍单份；其三，ARCHITECTURE 的 `PROTOCOL_HEADS = [...]` 字面声明降级为「给人看的镜像」（lint 仍断言它逐字存在）。被否决：连 RULES 一起收进 shared（引擎不 import 代码，收了也消不掉双份）、用 `.mts` 单文件省掉手写声明（Electron 内置 Node 不保证 type stripping，打包态风险不可控）、维持双侧副本只加强 lint（值仍是两份，lint 比对的是文本不是语义，prefix 正则这种「等价但不同写法」的漂移它看不见——本次 pickEffort/isMainTurn 仅顺序不同就是活例）。
