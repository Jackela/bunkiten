# 世界线一局一线，分叉靠一次性 fork.md 静默回退

进度按「世界线」隔离：一局一条，落在 `state/worlds/<worldId>/` 的三份文件（state.md / summary.md / story-tree.md），`state/worlds/index.json` 做索引；同一剧本可开任意多条平行线互不干扰，旧扁平 `state/*.md` 首次启动由 server 一次性迁入 `main`。分叉是**手动**动作：玩家在剧情图的某个已走过节点点「在此分叉」，只复制这三份文件并把进度指针回退到该节点（轮次清零、已剪枝恢复可达），**不自动推演任何内容**——分叉后的历史只由这一局的真实游玩积累。回退语义刻意做简：不存逐节点快照，而是写一份 `fork.md`，由引擎在下次 `继续世界：` 时一次性静默把 state/summary 回退到分叉节点的一致状态（分叉点之后的情节视为尚未发生），再删除 `fork.md`。否决了逐节点快照（三文件随每轮膨胀、回退脆）与「分叉时立刻回退」（把回退塞进客户端、破坏 state 的唯一事实源）。
