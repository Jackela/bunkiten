# 音频只由作者提供文件，协议行只报名字

剧本需要 BGM / 环境音 / 音效，但本项目**没有任何音频生成能力**（引擎手里只有 `image_gen`）。裁决：音频和美术一样是剧本自带数据——作者把文件放进 `presets/<剧本 id>/audio/`，命名 `<类型>-<名>.<扩展名>`（类型 ∈ `曲 | 环境 | 音效`，扩展名 ∈ `mp3 | ogg | m4a | wav | flac`，`<名>` 不得含 `|` 与换行）；引擎只发三条协议行 `【曲】<名>` / `【环境】<名>` / `【音效】<名>`，与【立绘】同为演出指令、各自单独成段、不进正文与历史，`停` 就是一个普通的名字（由客户端翻译成淡出，server 不做特判），【音效】无停止语义；server 只扫描与直服（`GET /api/audio?preset=` 列目录、`GET /audio?p=` 经白名单正则与 `path.resolve` 前缀校验后整文件直服、带 MIME 与长缓存），**不落盘、不生成、不进 `assetRegistry`**（`/api/assets` 从不列音频）。**缺失静默是端到端的**：目录不存在 = 该剧本没有音频，扫描回空数组不报错；索引里查不到「类型+名」时客户端只 `console.debug` 一行、no-op，玩家感知到的只是没有音乐，剧情照常推进。频率纪律写进 SKILL【音频】、导演层第 9 条与 RULES 第 6 句（每轮【曲】/【环境】至多各 1 次、【音效】至多 2 次，无把握就不发），「只在正戏使用」是同一套纪律的一部分（待命/规划/分项美术/重绘/创作装配/剧情编辑回合一律不发）。代价是随附剧本默认没有音频（仓库里四个 preset 都没有 `audio/` 目录，音频是纯可选增量：加音频只需往剧本目录丢文件、无需改代码）。被否决：音频生成（能力不存在，硬做只会产出不可控的体积与版权问题）、在标记里写路径（路径会随之被钉进历史与引擎上下文，换目录即断，且与【图】的路径语义混淆——【图】必须带路径、音频绝不能带）、把音频挂进【清单】集成音频（清单是章级美术需求、由制作流水线逐项点亮，音频是逐回合演出、由引擎按场景随时切，两者节奏根本不同）、内置音效库（违背 ADR-0008 的「一个剧本 = 一个自包含文件夹」，并让音频脱离故事）。
