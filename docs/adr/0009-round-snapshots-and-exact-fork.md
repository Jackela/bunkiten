# 逐轮快照代替推演式回退，fork.md 退为无快照兜底

ADR-0006 刻意不存快照：分叉只复制三份文件、把进度指针退回节点，再写一份 `fork.md` 让引擎在下次 `继续世界：` 时「按说明静默校准」state/summary。代价是回退精度挂在引擎的推理质量上——同一次分叉、不同模型或不同上下文会得到不同的「分叉点之后的情节尚未发生」，逐字一致没有保证；而且回退只能靠另开一条世界线，玩家无法在原地回到第 N 轮。本裁决改为**每个正戏回合自动落一份三文件全文快照**，回退与分叉都变成确定性的文件操作。落盘 `state/worlds/<worldId>/history/NNNN.json`（4 位递增、append-only；条目为 `{seq, at, kind, nodeId, chapterNo, files:{state,summary,tree}}`，三键是全文，当时不存在的文件为 null，`writeWorldFiles` 遇到 null 就删掉既有文件——否则「当时还不存在的 summary」会在回退后留下后来的内容）。写入点固定在 `sendPrompt` 内、`flushArtLines()` 之后、`busy = false` 之前（此刻本轮所有落盘已定型）；只为正戏回合写（`规划：`/`美术：`/`剧情：`/`装配。`/`创作模式：` 开头或含 `待命：` 的回合不推进剧情正文）；与上一条逐字全等则跳过，`seq > 9999` 停止写入并 warn once；世界 id 由 `sniffPreset` 一并跟踪，没定下世界就不写。**精确分叉**：显式 `seq` 命中优先，否则按 `nodeId` 取最早匹配的一条，以快照三文件建新世界（仍写 `fork.md`，但它只用于让引擎校准树，不再承担回退）；**原地回退**：先写一条 `kind:"backup"` 的当前三文件（`dedupe:false`，备份必须落盘否则恢复不可撤）再覆盖为目标快照，写备份失败即回退失败。与 ADR-0006 的关系：0006 的「不推演 + `fork.md` 静默回退」对**没有快照的世界继续有效**，作为兼容兜底逐字保留（无快照分叉的载荷与行为不变），有快照则逐字恢复、引擎完全不参与；回退成功后客户端还必须补发 `继续世界：`，因为磁盘三文件只是「档」，引擎会话里仍留着回退点之后的记忆。代价是磁盘随轮次线性增长（append-only、不 GC、上限 9999 轮）。被否决：引擎侧写快照（引擎是 prompt，没有 IO 纪律可依赖，且会让 state 出现第二个写者）、每次全量 diff（恢复要先重建，脆且慢）、只在分叉时快照（那就退不回任意一轮，原地回退与「快照 #N · 第 N 轮」的预览都无从实现）。

**修订（v1.13，ADR-0023）**：条目加 `prompt`（可重演的玩家输入；客户端的开局/续玩指令回填空串，由 `isDirectivePrompt` 在写入点判掉）；「与上一条逐字全等则跳过」改为「files 全等**且这次没有新的玩家输入**才跳过」——玩家输入永远落盘（files 相同也是新的一幕），空输入的读档回合只有真改了文件才落盘。理由与取舍（含导出包 v3、拒绝「日志端点 + 猜对齐」等备选）见 ADR-0023。
