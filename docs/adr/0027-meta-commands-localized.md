# 元命令与帮助本地化（/new-game /recap /presets /help 从引擎命令改客户端本地）

`/new-game`、`/recap`、`/presets`、`/help` 这四个元命令此前定义在 `.grok/commands/*.md`（grok CLI 的**项目级命令**），由客户端把命令名当提示词发给引擎、引擎读命令文件后自行应答。三条路都出了问题。

**其一，确认卡被切屏吃掉。** `/new-game` 的命令文件要求引擎「先确认——继续上局 / 重开同剧本 / 换剧本（优先一张选项卡；卡片工具不可用时按文本选项降级）」，而客户端在收到该回合后会**切屏**（旧的 `awaitCommand`：命令回合结束后回标题屏）。于是引擎的确认卡/确认选项正好落在**一个正在被切掉的屏**上——玩家要么看不到、要么看清时屏已经换了，「先确认」这个设计从未真正生效。**其二，Codex 后端没有命令。** `.grok/commands/` 是 grok CLI 的插件概念，Codex 后端（`codex-acp`）不加载它——同一个 `/new-game` 在 Codex 下会被当**普通输入**送进叙事，玩家看到的是「角色对着一句 slash 命令发呆」，而不是菜单。**其三，帮助文案漂移。** `/help` 的命令文件是一份手写的界面说明，界面一变它就与真实按钮/流程对不上（玩家按说明找不到入口），而引擎完全不可能知道客户端此刻画了什么。

裁决：**这四个元命令一律改客户端本地**，不再经过引擎一个回合。`/new-game` → 本地切屏（回标题屏）；`/presets` → 本地切回标题屏（轮播选本）；`/help` → 本地帮助面板（命令轨说明 / 快捷键卡 / 数据与备份说明 / 「打开日志目录」）；`/recap` → 本地「前情提要」面板——数据纯本地合成、零引擎回合：最近 N 条回合日志（`GET /api/logs`）+ `GET /api/state` 的时间地点 + 最新 turn 快照的 `summary`（取不到就降级为不带摘要）。落地面在 store：`src/store/slices/panels.ts` 出 `openHelp`/`closeHelp`/`openRecap`/`closeRecap`（外加回想接磁盘的 `loadHistoryPage`），`/new-game`、`/presets` 走本地的 `toTitle()`；`.grok/commands/{help,new-game,presets,recap}.md` 随之**删除**。

为什么本地是对的：其一，**这四个动作本来就不需要叙事引擎**——它们是界面导航与静态文案，引擎的调用链（spawn、回合、600s 超时、快照/日志）对它们是纯粹的浪费与故障面。其二，**引擎侧没有这几个命令，行为才一致**——四个命令文件删除后，grok 与 Codex 两条后端对「玩家按帮助/重开」的反应完全相同（都是客户端本地动作），不再有「grok 下能用、Codex 下不能用」的分裂，SKILL 里也不再需要为它们写例外（最高准则的 `玩家输入 /help 时除外` 那条 OOC 例外一并作废——见 SKILL）。其三，**帮助文案只有一个真源**：面板内容住在客户端组件里，和它描述的按钮在同一棵树里，改界面时它跟着改；引擎那份永远追不上。

代价与边界：其一，**帮助/前情提要是客户端的功能了**，它们的取数失败（`/api/logs` 挂、没有世界线）由面板自己给空态/错误态，不再有引擎兜底。其二，**前情提要是「提要」不是「流水账」**：它取最近几条日志压成单行（约 120 字/条），要完整历史看「回想」（`loadHistoryPage` 分页读同一份 logs）。其三，删掉命令文件后，**玩家手输的 `/new-game` 之类会落进叙事**（引擎会按自由输入处理）——与「玩家直接打字换剧本」同一条路，不再有魔法；界面上真正的入口是命令轨的「重开/换剧本」与标题屏角落簇的「帮助」。其四，`.grok/` 目录仍遵守 ADR-0021 的前提（只放 `commands/` 与 `skills/`）；命令文件删空后 `commands/` 目录留着（空目录不进 git），将来若再加项目级命令仍走同一信任通道。被否决：**保留命令文件、只在客户端拦一道**（双真源，且 Codex 下没有命令文件这条依然成立）；**把四个命令改写进 SKILL**（等于让引擎替客户端记菜单与界面文案，漂移照旧、还多花一个回合）；**帮助内容从服务端取**（静态文案没有理由过网络，且服务端不知道客户端的屏）。相关：`docs/ARCHITECTURE.md`「前端结构（src/）」「HTTP / SSE API 一览」、`src/store/slices/panels.ts`、`src/store/types.ts` 的 `RecapData`/`DiskHistory`。
