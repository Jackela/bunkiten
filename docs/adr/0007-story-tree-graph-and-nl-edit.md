# 剧情图：只读可视化 + 一句话自然语言改树，自研纯函数分层零依赖

剧情图屏把当前世界线的 `story-tree.md` 画成只读节点图（金=已走过、中性=可达、暗虚线=已剪枝、紫=嫁接、亮环=当前进度），玩家不改文件，而是用一句话自然语言编辑——底部输入 `剧情：<指令>`，引擎静默写回树文件并回一行摘要 + `【树】` 标记，客户端据此刷新（编辑回合不进历史；引擎忙时指令排队）。布局不引第三方图形库，用自研纯函数 `layoutTree`：最长路径分层 + Kahn 抗环 + 三次贝塞尔边，输入同则输出同、可被 node 直接单测（零新依赖）；超大树降级为滚动列表，避免画布失控。否决了通用图形库（依赖重、布局不可控）与「直接让玩家编辑 Markdown」（把解析负担与语法风险丢给玩家）。
