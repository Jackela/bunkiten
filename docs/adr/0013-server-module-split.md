# server 拆成入口 + 10 模块（入口保外部 import 面与契约 lint 钉面）

`server/acp-server.mjs` 拆模块前是两千余行的单文件：ACP 子进程、协议行解析、资产落盘、世界线 CRUD、逐轮快照、HTTP 路由与静态托管全部挤在一个 `startServer` 闭包里，改任何一块都得在同一份文件里翻上下文。裁决：拆成**入口 + 10 模块**（`config` 路径端口 / `protocol-lines` RULES 与五种协议行 parse* / `assets` 资产路径契约纯函数 / `presets` preset 解析与导出包 / `snapshots` 三文件与快照地基 / `worlds` 索引与 CRUD / `audio` 扫描 / `http-util` 本地端点防护与 MIME / `acp` 子进程封装 / `routes` 路由链），入口收敛到 653 行的「装配 + re-export」，但它保住三条外部路径、一条都不能挪走：`electron/main.js` 的动态 `import("../server/acp-server.mjs")`、集成 harness 的 `node server/acp-server.mjs` 子进程 spawn、契约 lint 对入口的懒 import（运行时值断言）与源码 grep（钉面——`pickEffort` 与 `isMainTurn` 的函数体必须引用 shared 真源的 `DIRECTIVE_PREFIX_RE`，`FONT_PRESETS`/`DIALOG_TEXTURES`/`DEFAULT_THEME` 三个主题字面量要与 `src/theme.ts` 比对，lint ⑥ 都从**入口源码**抓）；因此拆出模块的既有导出符号由入口逐名 re-export，electron/tests/doctor 的 import 面逐字不变。路由不做表驱动：`routes.mjs` 导出 `createRequestHandler(ctx)`，闭包能力由入口注入（SSE clients、`sendPrompt`、画廊/落盘、会话图片定位；`currentPresetId`/`sessionId` 用 getter，路由每次读最新值），if-chain 先匹配先赢且 `/app/` 前缀路由依赖 `startsWith`，表驱动没有净收益。ACP 会话做成 `acp.mjs` 的 `createAcpSession` 工厂（spawn/JSON-RPC/sessionId/boot/会话图片定位封装在内），与 HTTP 层的接缝只有 `onChunk`/`onSeg` 两个回调——流式【图】标记扫描与 SSE broadcast 留在入口，因为只有那里才有 `assetRegistry` 与 clients。入口与 `presets.mjs` 之间留一处**被契约强制的环形引用**：三个主题字面量声明在入口（lint 钉面要求），`presets.mjs` 的 `normalizeTheme` 反向 import 它们做逐键兜底——只在函数体内引用、不在模块顶层求值，ESM 环形引用安全；这份环形换来了「主题白名单字面量全 server 只此一份」。代价：其一，入口导出面比拆前多三个（`FONT_PRESETS`/`DIALOG_TEXTURES`/`DEFAULT_THEME` 必须导出给 presets.mjs 引用）；其二，入口头部的模块地图注释与 re-export 块要随模块增删同步维护（漏一个 re-export，外部 import 立刻断）。被否决：全表驱动路由（`/app/` 前缀匹配无净收益，见上）、ACP 封装暂留入口（回调接缝可行，就不留两份实现）。
