# a11y 基线：跟随系统的动效降级 + 三档对比度 token + 全局焦点环

无障碍此前是空白：动效不认系统「减少动态效果」（前庭敏感用户只能硬忍）、文字对比度靠散落手写的 `text-ink/<透明度>` 档位（更淡的档位曾被用于可读正文——v1.7 审查抓过一次）、焦点样式是 19 处 `outline-none` 各组件自管（键盘用户看不见焦点在哪）。裁决三件事，全部收在全局层而不是逐组件。其一，**动效降级跟随系统、不设游戏内开关**：OS 级偏好是用户已经做过的一次选择，设置屏再造一个必然出现「游戏开关与系统开关打架」的中间态；framer-motion 由 App 根的 `<MotionConfig reducedMotion="user">` 一处全局接管——**只停位移/布局动画**（transform、layout 瞬时化，元素照常挂载），交叉淡入**保留**（framer-motion 13 的 `reducedMotion` 不覆盖 opacity，而淡入正是 WCAG 推荐的位移替代——要消除的是位移感，不是一切变化）；CSS keyframes（`animate-pulse`/`animate-spin`）由 `global.css` 的 `@media (prefers-reduced-motion: reduce)` 置 `animation: none`（元素静止仍渲染，光标可见性不丢）；打字机在组件内用 `matchMedia` 检测（挂载读一次 + 跟随 change 事件），开启时按 0 间隔整段显示——复用「瞬间」档的呈现路径，**不改用户的文字速度设置档位**。其二，**对比度三档语义 token**（`@theme inline` 直混透明度，按最深面板底实测）：`ink-body` 80% ≈10.2:1（次级正文/长说明）、`ink-hint` 60% ≈6.1:1（**提示文字下限**——快捷键提示、元信息、状态辅助行、字段标签、图例、空态文案）、`ink-faint` 45% ≈3.9:1（不达 4.5:1，**仅限**禁用态（WCAG 对 disabled 控件豁免）、纯装饰符号、≥18px bold 或 ≥24px 大字）——**faint 用于可读内容即违例**；正文继续 `text-ink`（strong ≈15.8:1），新增文字按语义取 token、不再手写低档透明度（既有 60% 及以上档位未迁移、与新 token 并存）。其三，**全局 `:focus-visible` 焦点环**：`:where(button, a, input, select, textarea, [tabindex]):focus-visible` 画 `outline: 2px solid var(--accent2)` + 2px 偏移，只响应键盘焦点（鼠标点击不闪环）；规则写在 **unlayered 区**（级联层外的规则优先于 Tailwind v4 的 utilities 层）且 `:where()` 零特异性——任何工具类（包括未来想再加的 `focus:outline-none`）都盖不住这圈环，组件里因此不再需要也不允许 `outline-none`；SVG 焦点节点（剧情图 `<g tabindex>`）的 UA 级 `outline:auto` 由 `:where(svg [tabindex]):focus:not(:focus-visible)` 单独抑制（键盘环与鼠标环互斥不冲突）；文本输入框任何聚焦方式都带环是 UA 有意为之的可访问性行为，不压制。代价：其一，一次性 codemod 替换约 100 处类名（手写低档透明度 → 语义 token）；其二，「大字」边界（≥18px bold / ≥24px）靠人审，组件里没有 px 计数器。被否决：每组件自管 focus 样式（19 处 `outline-none` 时代的漂移就是证据）、游戏内动效开关（见上）、在 hint 之下再设一档「可读的 faint」（3.9:1 对正文就是不可读，设了就会被用）。
