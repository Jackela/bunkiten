# bunkiten v1.8.0

本版是一次「看得见」的整理：把界面收成一套**壳层版式系统**（五个壳层屏共用页框、面板/遮罩 token、12→28 的字号阶梯），修掉**立绘从来没占过版面**的布局盒 bug（对话框不再压住立绘），把玩家侧的文案洗成玩家话（回合/轮 → 幕、快照 → 存档点、引擎口吻统一翻译），并补齐几处早就该有的形态（章节过场卡、对话面板上的自动/快进、标题屏「继续上次」、剧情图章节切换器、家谱缩放平移、世界线行的 `⋯` 菜单）。旧存档直接用，无需任何迁移。

## 壳层版式系统

- **壳层页框（`ShellPage`）**：世界线 / 捏主角 / 制作中 / 设置 / 画廊五屏共用同一个外框——满幅主题底、全仓唯一一处定宽宽栏、统一表头（眉标 → 屏标题 + 主题色短分隔线 → 右侧动作簇）、可选 ≥xl 右栏（窄屏顺序落到正文之后，不做抽屉）。它钉住的规则是：**壳层屏不再各屏自写居中窄栏**，屏内区块撑满可用宽度、靠栅格与多列组织信息。
- **表面与遮罩 token**：`bg-panel` / `bg-panel-strong` / `bg-scrim` / `bg-scrim-soft` 取代散在各组件类名里的 rgba 字面量；`.shell-backdrop`（满幅主题洗色 + 底部压深，压住亮底图让面板与文字对比度稳定）与 `.shell-panel`（底色 + 模糊 + 一道发丝描边）刻意写在级联层外——优先级高于工具类，屏里随手写的渐变盖不掉它。
- **字号阶梯（12→28）**：八档字号以 `@theme` 单源落地——`text-micro` 12（角标/徽章这类不承载细读信息的短标记）、`text-meta` 13（**需要读的文字的下限**：提示、图例、元信息）、`text-ui` 14（标签与次级正文）、`text-body` 16、`text-read` 17（对话框叙事正文）、`text-lead` 18、`text-title` 20（屏标题）、`text-display` 28（封面与主标题）。全仓不再手写 `text-[Npx]`——字号要改只有一处。

## 玩家文案清洗

引擎口吻与内部标识符一律不上玩家的屏：

- **回合/轮 → 幕**：一个正戏回合 = 一幕，幕号就是逐轮快照序号（第 N 幕 ⟺ `history/NNNN.json` 的 seq N），所以它确定、可回溯。历史抽屉与剧情图都按幕说话，`快照 #N` 与「第 N 轮」不再上屏。
- **快照 → 存档点**：剧情图节点标「存档点 · 第 N 幕」、对比入口写「与上一个存档点对比（第 N 幕 → 第 M 幕）」、历史里的分割线写「—— 第 N 幕已重演 ——」。磁盘上它照旧是 `history/NNNN.json`，改名只动呈现层。
- **引擎状态串翻译**：`playerStatus` 是唯一映射点（「引擎演绎中…」→「故事展开中…」、「撰写章节大纲…」→「章节筹备中…」、`出错：X` → `出错了：X`，表外状态原样透传），顶栏、制作中屏与读屏播报（aria-live）三处共用。
- **分叉备注不再写裸 id**：血缘只走 `forkedFrom` 与家谱连线；旧版 server 自动写进世界线备注的「分叉自 <id> @ <节点>」按「没有备注」处理——`note` 会被显示层当成世界名，那等于把 slug 端给玩家。

## 画面与过场

- **立绘真实布局盒（bug 修复）**：此前的包裹层是 shrink-to-fit、宽度恒为 0，`img` 的 `max-w-full` 因此解析成 `max-width:0`——立绘实际上从来没占过版面。现在立绘层用 grid 单格堆叠（两张图同格重叠，差分交叉淡入照旧）、行高显式 `1fr`，图片拿到真实布局盒；配套 `.portrait-reserve` 在 ≥lg 给对话区的满宽外层预留 `min(40vw,420px)`——可用宽度收窄、居中区整体左移，对话框不再压住立绘，面板自身也不会被挤窄。
- **章节过场卡**：章号一变，画面正中亮一次「第 N 章」（约 2.2 秒，末尾淡出）。它挂在 App 常驻层（不在游戏屏里），所以从画廊/剧情图返回游戏屏不会同一章再亮一次；不拦点击、不抢焦点。
- **对话面板的「自动 / 快进」**：面板右上角两个小控件——「自动」与设置屏的自动前进是同一份设置（开着落到 3 秒档，关掉连已排的倒计时一起取消），「快进」立即显示全文（打完即置灰）。

## 各屏形态

- **标题屏**：加产品字标（`bunkiten` / `分岐点`）与左下「**继续上次**」——一键直通最近游玩的那条世界线，不必先选卡带再选世界线。
- **剧情图**：顶部**章节切换器**列出解析出的每一章，带进度指针的那章标「当前」，点谁画谁（从前只画进度章那一章）；`归档` 章只剩目录信息，点它给一句实话而不是装作能打开；节点详情 ≥lg 住右侧 380px 栏（sticky 自滚），窄屏回到画布下方。
- **家谱**：补上与剧情图同款的画布能力——滚轮指针锚点缩放、拖拽平移、双击复位、`±` 与「适应」、`+ - 0`；渲染宽度**只封上界**（单节点 ≈270px），两三条线的小森林不再被等比撑成巨卡，森林更大时照旧铺满可用宽度。
- **世界线行**：行上动作收成一个主行动**「继续」+ 一个 `⋯` 菜单**（改名 / 导出 `.world.json` / 删除；删除的两段确认收在菜单内，Esc 或点菜单外面即关）——不再四个按钮平铺。

## 架构与工程

- **构建拆包**：产物按 `react` / `motion` / `vendor` 三组拆 chunk——大依赖不再和业务代码挤在一个包里（单包体积告警与「改一行代码整包缓存失效」都因此缓解），只动产物分组、不改任何 import 语义。
- **排版收口**：面板底色与遮罩从组件类名里的 rgba 字面量收成 token，字号收成单一阶梯——这两件是「改一处、全站生效」的前提，也是这次能把五个壳层屏统一到一套版式的原因。
- **测试**：单测 + 集成全量 **415 例**（parser 65 / server 106 / crafting 52 / treeLayout 7 / genealogy 8 / diff 8 / doctor 12 / ui 130 / 集成 27），契约 lint 自身不计入口径；新增用例覆盖对话面板自动/快进、标题屏「继续上次」、剧情图章节切换器、家谱缩放与渲染宽度上界、立绘占位与「对话区不压立绘」。

## 升级须知

- **无需迁移，旧存档直接用**：世界线、快照、设置、剧本与素材全部原样兼容；覆盖安装或解压新包后启动即可。
- **界面看着变了但操作没变**：世界线行上的改名/导出/删除收进了 `⋯` 菜单，其余按钮的位置与行为照旧；窄屏上壳层屏的右栏内容顺序排在正文之后。
- **玩家屏上不再出现内部词**：`快照 #N`、「第 N 轮」、裸 `worldId` 一律换成「存档点」「第 N 幕」「世界线显示名」——手边有旧截图或攻略的话，按这个对照读。
