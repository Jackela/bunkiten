# bunkiten v1.7.0

本版把「后悔药」补全（不满意这一轮就**重掷**，回退不再留下说不清的历史）、给游戏加了三个观察面（世界线**家谱**、快照**对比**、**角色面板**），让剧本可以打包分享、作者有体检工具，并为无障碍铺了基线（跟随系统的动效降级、全局焦点环、对比度分级）；引擎侧补了可靠性（回合原文日志、漏写选项段自动追问），工程侧先铺了一张够大的测试安全网。旧存档直接用，无需任何迁移。

## 先铺测试安全网

这版动的地方多，所以先把网织密，再往上面放功能：

- **假引擎确定性 UI e2e**（`tests/e2e-ui/`，12 个场景）：用脚本化的假引擎 + 真服务端 + 真浏览器跑开局、设置、键盘、画廊、剧情图、世界线、回退、重掷、动效降级、焦点、角色面板、剧本导入导出——秒级、不依赖登录、随 CI 跑（真引擎冒烟仍只在本机）。
- **契约 lint 升级为真源断言**：协议常量收进 `shared/protocol.mjs` 唯一真源后，lint 不再比对两份源码文本，而是断言「真源只有一份、双侧都从它取值」——`pickEffort` 与 `isMainTurn` 此前各持一份手写前缀正则、恰好等价但随时可能分叉的隐患被连根拔掉。
- **覆盖率防下滑线**（`npm run test:coverage`）：同一批测试加覆盖率仪表，阈值 = 当前基线四舍五入 −2pp，CI 用它替代单独的测试步骤（避免双跑），并上传 HTML 报告。
- **server 侧类型门禁**（`npm run typecheck:server`）：`server/`、`shared/`、`scripts/` 的 `.mjs` 全部开 strict 检查（类型全靠 JSDoc），进 CI。
- 测试从 294 例扩到 **399 例**（parser 65 / server 106 / crafting 52 / treeLayout 7 / genealogy 8 / diff 8 / doctor 12 / ui 114 / 集成 27；契约 lint 自身不计入口径）。

## 回退与重掷

- **重掷本回合**：游戏屏右侧按钮轨新增「重掷」——撤销**刚走完的这一轮**（画面、进度、存档一起退回），再把你刚才那句输入原样重发一遍，让引擎重新演绎。本世界第一轮不能重掷（入口在攒够两条回合快照前不出现，续玩时会读一下磁盘上的旧快照数）；新回合结束即可再掷（连掷）。排队中的重掷在你换世界线/换剧本时自动作废。
- **回退不再「说不清」**：回退（或重掷）后，历史里只插一条分割线（「已回退到快照 #N」/「重掷本回合」），旧幕置灰但**不删**——你随时还能看回退前发生了什么。
- **待重同步**：回退覆盖的是磁盘存档，引擎脑子里的剧情要靠一次「重新读档」对齐。重读期间顶栏有「待重同步」徽章；万一失败（引擎忙/网络抖动），徽章旁边长出「再同步」按钮，点一下重试，成功后排队中的重掷会自动跟上。

## 新视图与面板

- **家谱（世界线屏）**：列表 ↔ 家谱一键切换。家谱把「哪条线从哪条线的哪个节点分叉」画成一张血缘森林图，多周目的来龙去脉一眼看清；父线已删的孤儿线带 ⌫ 徽章；方向键在图上走位（←→ 同层、↑↓ 跨层），Enter 选中后快捷条直接「继续」。
- **快照对比（剧情图节点详情）**：「与上一快照对比」把两份存档逐行 diff——剧情状态 / 前情摘要 / 剧情树三个 tab，tab 头给 +N −M 摘要，没变的行折叠只留上下文。回退前的自动备份也算合法基线，所以回退后的第一次对比也有得比。对比是你主动点开的，secret/导演手记按原文显示。
- **角色面板（游戏屏侧栏）**：随时查看引擎维护的角色状态——好感度（数字 + 细进度条）、表情徽章、秘密（默认折叠防剧透，点开才看）、导演手记、Flags 与未回收伏笔。面板开着时每回合后自动刷新；数据直读当前世界的 state.md，不另建缓存。

## 分享与作者工具

- **剧本导出包**：标题屏当前卡带「导出」→ 一个 `<剧本 id>.preset.json` 单文件（preset.md + 全部立绘/背景/封面 + 音频）；朋友点「导入剧本」选文件，剧本立刻进轮播。重名自动落成 `<id>-2`，绝不覆盖已有剧本；单包上限 50MB。导入侧做全量校验（文件名、扩展名、base64、Windows 保留名），任何一项不合法整包拒绝，不会写出半个剧本。
- **`npm run doctor` 剧本体体检**（作者侧 CLI）：frontmatter 必填键与 id=目录名、theme 坏值回退预警（server 与客户端两层判定都会查）、`# 主要角色` 与建议字段、封面（只认 `cover.jpg`，手放成 `.jpeg` 会被点名）、`assets/`·`audio/` 文件名契约、孤儿素材。每个剧本一行小结加明细；**退出码非 0 当且仅当有 error**（warning 只是提示）。刻意不进 CI——preset 健康度随游玩数据漂移，门禁化会误伤。

## 无障碍与视觉

- **动效降级跟随系统**：系统开了「减少动态效果」（macOS 辅助功能 / Windows 视觉效果），游戏自动跟随——位移类动效瞬时化、脉冲光标静止、打字机整段显示；交叉淡入保留（这是无障碍推荐的位移替代）。**刻意不加游戏内开关**：系统里已经选过一次，游戏再发明一个只会出现「两个开关打架」的中间态。
- **全局焦点环**：键盘 Tab/方向键走到哪，哪里就有一圈主题色描边（鼠标点击不闪环）。此前 19 处 `outline-none` 各组件自管，键盘玩家经常找不到焦点在哪。默认兜底主题的 `accent2` 同批调为中性浅色 `#e8e4da`（它就是焦点环的颜色，中性色在任何母题底色上都稳定）。
- **文字对比度三档**：正文/提示/装饰各归各位（提示档 ≥6:1、正文更高），最低档只许用于禁用态与装饰——这版把散落手写的透明度档位收编成语义 token，并在收尾时完成**全量迁移**（60–90 手写档位一并并入三档，全仓不再有 `text-ink/<透明度>`）。
- **主题扩展（作者可写进 preset）**：frontmatter `theme` 新增 `font`（serif / song / kai / hei 四档系统字体族，离线无 webfont）与 `dialog`（plain / silk / paper / glass 四档对话框质感）——配色、字体、对话框质感随剧本切换。

## 引擎侧可靠性

- **回合原文日志**：每个正戏回合的「你发了什么 + 引擎回了什么」落一份 `logs/NNNN.json`（append-only、不清理）。引擎某轮胡言乱语或漏协议段，事后有据可查。只写不读（排障直接看文件），不进世界线导出包——它是本机的黑匣子，不是可迁移的档。
- **缺选项段自动追问**：每轮协议要求引擎以 `**行动**` 选项段收尾，但它偶尔忘写。现在 server 会在**同一回合内**自动追问一次「补个回合尾」——玩家看到的还是同一回合的补全（零感知），追问后仍缺或追问失败就放弃并留痕，绝不因此把一回合好的叙事判死。章末回合（输出章标记的那轮）本来就不出选项，豁免。
- **引擎报错按回合失败传播**：引擎按协议回 error（而非断流/超时）时，此前会被误当成功回合（照写快照、HTTP 200）；现在正确走失败路径——界面收到错误事件、HTTP 409、**不写快照**。
- **读路径索引化**：快照列表读取带元信息缓存（**逐文件复用**：目录没变不重解析，变更后也只重解析新增/被覆盖的那个文件），跨会话找图走会话图索引（不再每次全量重扫）——世界线玩得越久越能感觉到。

## 架构与工程

- **协议常量单一真源**（ADR-0012）：`PROTOCOL_HEADS`、音频白名单与直服正则、美术类型字面与资产文件名正则（`ART_KINDS`/`ASSET_KINDS`/`ASSET_FILE_RE`）、指令前缀正则全部收进零依赖的 `shared/protocol.mjs`，客户端与服务端 import 同一份值；`RULES`（给引擎的六句纪律）刻意不收编——引擎只读 `.grok/` 提示词文件、不 import 代码，双份 + lint 逐字比对仍是正确机制。
- **server 拆模块**（ADR-0013）：单文件两千余行拆成入口 + 10 模块（RULES 与协议行解析、HTTP 路由、ACP 会话、世界线、快照、preset 解析、资产路径、音频、HTTP 工具、路径配置各归其位），入口保住外部 import 面与契约 lint 钉面，外部零改动。
- **删除进回收站**（ADR-0014）：世界线与画廊素材的删除不再直删，先整体挪进 `state/trash/`（不自动清理、没有恢复 UI）；跨设备挂载等 rename 失败时回退直删，「删除」语义本身绝不失败。
- **回合日志与质量守卫**（ADR-0015）、**剧本导出包**（ADR-0016）、**a11y 基线**（ADR-0017）各有裁决记录；ADR 目录现为 0001–0017。

## 已知限制与不做清单

- **快照与日志只增不减**：`history/`（三文件全文）与 `logs/`（回合原文）都 append-only、不清理；单条世界线 `seq > 9999` 后两者都停写（回退精度停在最后一条快照）。磁盘换可回溯性，长世界线会很占地方。
- **回收站不自动清理**：删掉的世界线/素材在 `state/trash/` 里只进不出，想清就手动删那个目录；自动清退必然引入「保留几天」这类拍脑袋参数，不做。
- **剧本导出包不带进度**：它分享的是剧本本身（文件 + 素材 + 音频），世界线进度走自己的 `.world.json` 导出。`logs/` 不进任何导出包。
- **快照对比不遮剧透**：diff 面板按原文显示 state.md（含引擎维护的秘密字段）——它是你主动打开的两份自己存档的对比。
- **无游戏内动效开关**：跟随系统偏好是刻意裁决，不会再加（理由见 ADR-0017）。
- **未签名包不能自动更新（mac）**：与 v1.6 相同——仓库未配签名 secrets 时发布的就是未签名包，mac 上自动更新会静默失败，更新请重新下载覆盖安装（存档不受影响）。
- **本地端点无鉴权**：server 是本机专用，来源校验只挡跨站浏览器请求，不防本机其他进程（同 v1.6）。

## 升级须知

- **无需迁移，旧存档直接用**：世界线、快照、设置、剧本与素材全部原样兼容；覆盖安装或解压新包后启动即可。
- **两个新目录会自动出现**：`state/trash/`（删除的回收站，只有删除动作才会用到）与 `state/worlds/<世界线>/logs/`（回合原文日志，从升级后第一个正戏回合开始记——旧回合没有日志属正常）。都是运行时数据，不打进任何安装包。
- **旧世界线照常能玩**：没有快照的老存档（v1.5 时代的）依旧走兼容路径分叉；重掷与快照对比依赖逐轮快照，从这一版继续玩下去自然就有了。
- **分享剧本换新姿势**：以前拷文件夹，现在标题屏导出 → 对方导入；老的拷文件夹方式依旧有效（两者等价）。
