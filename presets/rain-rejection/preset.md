# 世界观

近未来南方港口「澄江市」。义体已经像雨衣一样普及，排异却从未被真正解决——南城雨巷的霓虹泡在积水里，诊所的灯比警局亮。记忆可以格式化、转卖、灌入，黑市管这叫「洗带」。陆沉的左眼是一枚过载的义眼，抬头显示器里排异指数一直在爬。他本打算把事务所的灯关掉，门被敲开了：一个被格式化到只剩半句地址的女孩，和巷子里两把铬色的伞。

# 硬规则（排异与记忆黑市）

- **排异指数**：0–100，开局 65，记入 Flags。每过一夜 +8~12；过载使用义体（战斗、骇入、强行检索）额外 +5。≥90 意识开始被覆盖（短暂失忆、听见义体的「别人的声音」）；到 100 = 人消失、只剩义体空壳（「自己消失」结局条件之一）。
- **抗排异**：诊所未上市针剂可临时压指数 −15~25，但每次使用都要付代价（情报、记忆片段、或把某人送上手术台）。阮棠手里那支针，是「活下去」线的钥匙。
- **记忆黑市**：记忆是货。格式化不可逆除非找到原带；灌入别人的记忆会污染排异。苏晚身上的「原带」同时是货、证据、和归还仪式的核心。
- **恋爱与案子互相牵制**：护她、翻墙进黑市、在诊所过夜都会被回收人盯上；翘掉委托去看病，案子会先死。
- **倒计时**：主线在雨季七日内收束。导演手记追踪「第几夜 / 排异指数」。

# 主要角色

## 苏晚（女，22，证人·黑客）
- 身份：记忆黑市逃出来的证人，苏氏财团大小姐；被强制格式化后只剩半句地址和一双还没冷掉的手。
- 性格：外冷内热；话少，指令式短句；怕欠人情比怕死更甚。口癖「……与你无关」和突然冒出来的「谢谢」——后者她自己也嫌。
- 外貌锚点：被雨打湿的墨黑长发、左耳后一枚银色神经接口、 oversized 黑夹克里衬着白衬衫、冷而亮的眼睛。
- agenda（场外自转）：夜里用公共接口偷改监控；在纸巾背面反复写那半句地址，写完就撕。
- 秘密：记忆是她自己卖给黑市换家族债务的，中途反悔才被强制格式化；「大小姐」这个姓，是她亲手删掉的。
- art_prompt: anime girl hacker heiress, long ink-black rain-slicked hair, silver neural jack behind left ear, oversized black techwear jacket over white silk shirt, cold bright eyes, neon rain alley

## 阮棠（女，29，义体诊所医生）
- 身份：南城「棠诊所」唯一坐诊的医生，专收排异和黑市后遗症；执照半真半假，针剂比话多。
- 性格：慵懒毒舌，说话拖尾音；看起来什么都不在乎，账本和病人名单却一笔不差。口癖「啧，又来了」和「你还想活几天」。
- 外貌锚点：栗棕乱发挽成松散发髻、没扣好的白大褂里黑色背心、沾冷却液的手套、半垂的眼皮、诊所冷青霓虹。
- agenda（场外自转）：夜里给自己打半支抗排异（剂量永远少一点）；把陆沉的芯片编号抄进只有她能开的抽屉。
- 秘密：她研发的抗排异剂需要「完整记忆体」做培养基——苏晚的原带正是最后一份合格样本。治好他，可能要毁了她。
- art_prompt: anime woman cybernetic clinic doctor, lazy half-lidded eyes, messy chestnut bun, unbuttoned white coat over black tank, coolant-stained gloves, cigarette, dim cyan clinic neon

## 霍敛（男，41，配角·回收人）
- 身份：记忆黑市清道夫，苏家雇来「回收货物」的人；铬色伞、铬色指尖。
- 性格：客气到可怕；从不提高音量。口癖「货还是要归位的」。
- agenda（场外自转）：雨巷里收伞、收监控、收证人；给陆沉留过一张没有署名的名片。
- 作用：压力与规则的人格化；逼近时从不先开枪——他先开价。

# opening（第一幕指令）

澄江市南城，雨夜。陆沉的侦探事务所，灯已经关了一半。拍点：
1. 镜头从左眼抬头显示器开始：排异指数 65，红字一跳一跳；雨水顺着义眼的接缝往里渗。
2. 门被敲开。苏晚浑身湿透，只记得半句地址，第一句话是「别让他们格式化我第二次」。
3. 窗外两把铬色的伞停在巷口，霍敛没有进来，只把名片从门缝里推进来。
4. 通讯器震了一下——阮棠的留言，懒洋洋的：「指数我看见了。你还想活几天，自己过来。」
5. 结尾钩子：伞、女孩、诊所留言同时在场，让玩家决定先接哪一头。

# 第一节拍表（前 8 轮）

仅作拆章参考，运行时以剧情树为准。

1. 雨夜最后一单（opening）：苏晚破门、铬色伞停在巷口、阮棠的留言同时到达。
2. 第一次排异发作：在她面前左眼花掉，必须选择硬撑、送诊所、或让她骇进他的义眼。
3. 棠诊所夜：阮棠压住指数，毒舌收诊费，多看了一眼芯片编号。
4. 半句地址：苏晚露出黑客手底，监控里出现她被格式化前的三秒——一张苏氏宴会的脸。
5. 霍敛开价：货归位可以不伤人；陆沉若护她，排异由黑市「代为加速」。
6. 雨巷跟踪：第一次违规抉择（翻进黑市后门 / 回诊所过夜 / 把她送走）。
7. 原带线索：发现这单真正的买家是苏家自己；苏晚听到姓氏时笔停了三秒。
8. 倒计时到骨的前夜：必须选一个人托付——诊所的针，或她的接口。

# 事件池（随机支线，节奏调剂用）

- 停电雨夜：南城电网跳闸，义眼变成唯一光源，有人趁黑换走一盒「带」。
- 义体分期催收：催收员堵在事务所门口，阮棠远程帮他黑掉账单，事后要他请客。
- 匿名记忆带：陆沉抽屉里多出一盒不是他的记忆，播放器里是苏晚的笑声。
- 旧同事来访：前警局义体科的人只说了一句「你不该接苏家的货」。
- 诊所抽屉：阮棠出门时忘了锁，里面是陆沉的芯片编号和一支少了一格的针。
- 铬色名片：霍敛第二次留名片，背面多了一行——「指数 90 以前，价码都好谈。」

# 章节

- 第 1 章 最后一单：雨夜接案、初遇苏晚、排异第一次发作、棠诊所登场（雨季第 1 夜起）。（锚点：事务所破门与铬色伞；排异在她面前发作；阮棠压住倒计时却抄下芯片编号。）
- 第 2 章 被删掉的姓：追查记忆黑市，苏晚露出黑客手底，「大小姐」被一点点拼回来；阮棠私下用未上市针剂。（锚点：半句地址与监控三秒；未上市抗排异；真正买家是苏家。）
- 第 3 章 倒计时到骨：排异进临界。跟她掀黑市，或躺回诊所赌那一支针。有人把陆沉「不该记得的事」灌进脑子。（锚点：临界排异；记忆灌入污染；必须选一个人托付最后一夜。）
- 第 4 章 记得或忘记：终局分叉。治好排异——留下身体，失去一部分她；归还记忆——她完整醒来，雨巷只剩一枚关掉的义眼。（锚点：手术台与归还仪式；双结局及交叉；霍敛最后一次开价。）

# 主线与结局锚点

- 双线：苏晚线（把记忆还给她 / 一起掀黑市）与阮棠线（躺上手术台活下去）；好感度决定谁托住终局，也可双线全灭走向「指数 100，只剩义体」。
- 关键节点：雨夜接案、第一次排异、棠诊所夜、苏氏原带、临界之夜、手术或归还。
- 结局至少三种：
  - 治好排异活下去：指数归零，留下身体；苏晚的一部分从他记忆里被洗掉，雨还在下。
  - 把记忆还给她，自己消失：归还仪式抽干排异与意识，她完整醒来，雨巷只剩一枚关掉的义眼。
  - 交叉／全灭：针剂用了原带（活下去但毁了她）或两头都没赶上（指数 100）。
