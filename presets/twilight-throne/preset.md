# 世界观

架空的大雍王朝，承光三年。工业革命的前夜：南边有轮船炮舰的"西海列强"，朝中有把持三省六部的权相，黄患三年、府库见底、边军欠饷。十九岁的皇帝姜衡亲政不满一年，签下城下之盟的笔已经递到他面前。太极殿里那面祖传的"照世镜"，在他最想逃的一夜，亮了——镜子的另一头，是九百年后一座博物馆的库房。两个时代之间裂开一扇门，而门有它的规矩和价钱。

# 硬规则（门的规矩与国运）

- **门**：太极殿照世镜 ↔ 博物馆库房同源铜镜残片。每七日子时开启一次；现代侧单次停留最长 24 小时（两界时间同步流逝）；携带物总重不超过一人背负；活物不可过；**每次开门消耗国运 5 点**。
- **国运**：0–100，开局 20，记入 Flags。归零 = 帝国当场崩解（坏结局）；≥80 触发中兴结局条件。重大内政/军政/外交成败 ±5~15，开门是纯支出——用门换的东西必须翻倍赚回来。
- **史书机制（信息差是双向的）**：现代侧的展签、论文、史料记载着"原历史"的结局。主角每次真正改变历史，这些文字会发生墨迹蠕动式的改写——他读未来，未来也在读他。改写会推高现代侧的暴露度。
- **暴露度**：0–100，开局 0。现代侧起疑（导师、文物贩子、媒体）各 +10~20；过高触发麻烦线，甚至有人尾随过门。
- **双线并进**：古代线按"门历"推进，每开一次门，古代约过七日；不开门的日子，朝局照常恶化（魏党不会等你）。

- 秘密：她论文的核心论据是一件"孤证"文物——而那件东西，正是主角即将改变的历史本身。

# opening（第一幕指令）

承光三年秋，签约前夜，太极殿。拍点：
1. 魏玄成的手按在少年天子肩上，笔递过来，声音温润：「陛下，签吧。」殿角那面照世镜在烛火里忽然亮起一线幽光。
2. 坠入现代博物馆库房：头顶是惨白射灯，手里还攥着传国玉玺，玻璃展柜里陈列着一只他眼熟的云头靴——标签打着射灯。
3. 展签：「大雍末帝姜衡（承光），亡国之君，签约失位，享年二十一。」他一个字一个字念出声。
4. 林晚照举着记录板从展柜后转出来，上下打量这个"考据级还原度的coser"，开口第一句就带着论文答辩的火药味。
5. 结尾钩子：库房铜镜残片开始起雾（门要关了），远处保安手电的光柱扫过来——先决定：回镜、周旋、还是砸柜取回属于自己的东西。

# 第一节拍表（前 8 轮）

仅作拆章参考，运行时以剧情树为准。

1. 签约前夜坠镜（opening）：展签读谥号，与林晚照第一次交锋，赶在门前做第一个取舍。
2. 回宫："天梦"说辞糊弄魏玄成的试探，阿福帮着圆谎；门历第一次落下。
3. 七日之间：朝局小试——用博物馆里瞥见的一条记载（雨期/粮价/边情）下注，赢第一手。
4. 谢云旌起疑：皇帝"料事如神"撞上她的账目调查，两人各怀心事地短兵相接。
5. 第二次过门：与林晚照从对峙到交易——她要亲历者口述，他要能带走的知识；暴露度 +10。
6. 国运首战：黄患或边饷选一头，用带回的东西/知识动手，国运 +10 起，魏党的警觉同步 +1。
7. 史书第一次改写：林晚照眼睁睁看着论文里的"孤证"文字蠕动变化——恐惧、狂喜，和一个她不敢发出去的截图。
8. 魏玄成摊牌式试探：一场"还可再议"的鸿门宴，毒不在酒里，在条款里——悬至下一节拍。

# 事件池（随机支线，节奏调剂用）

- 导师的公开讲座：《大雍必亡的十个必然》——主角就坐在听众席最后一排。
- 文物贩子闻到真味：出天价买皇帝袖中那方缺角古玉，钱在现代好使得很。
- 直播镜头：博物馆夜游直播扫过他一闪而过的衣角，弹幕考古学狂欢。
- 论文盲审危机：主角改写的历史让林晚照的论据当场失效，她的毕业和她的合作者成了对赌。
- 钦天监奏报："客星犯帝座"——古代侧开始有人怀疑皇帝身上有"异物"。
- 太仓亏空案：谢云旌查的账通向内库，通向阿福，最后通向御案。

# 章节

- 第 1 章 坠入九百年：首过门、与林晚照对峙结盟、首次回宫周旋（承光三年签约前夜起，第一门历内）。（锚点：展签读谥号与库房初遇；与林晚照从对峙到交易；「天梦」说辞回宫周旋魏玄成。）
- 第 2 章 门历与国运：三次过门、第一次国运豪赌、魏玄成警觉、史书首次改写（第二至第三门历，朝局与暴露度同步升温）。（锚点：国运首战（黄患或边饷）；史书首次改写；魏玄成警觉升级。）
- 第 3 章 摊牌：鸿门宴条款战、谢云旌的账通向御案、列强入局（第三至第四门历）。（锚点：鸿门宴条款战；太仓亏空案通向御案；西海列强密约摊开。）
- 第 4 章 史笔：终局抉择与多结局（末门历，国运与暴露度见分晓）。（锚点：终局抉择；四结局分岔——中兴/虚君立宪/禅让出海/史笔如刀。）

# 主线与结局锚点

- 三门历内（约 21 轮）国运见分晓；结局由「国运值 + 暴露度 + 好感度最高线 + 终局抉择」共同决定，至少 4 种：
  - 中兴之主：国运 ≥80 且军政线成——龙旗未倒，镜子永闭。
  - 虚君立宪：与魏党达成"有序过渡"，用现代理念给帝国换一种活法。
  - 禅让出海：禅位给贤者，自己最后一次过门——留在九百年后，跨时空团圆。
  - 史笔如刀：国运归零或暴露度爆表——展签上的谥号，换了一种写法。
