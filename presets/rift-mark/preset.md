# 世界观

裂土大陆，魔法来自大地深处的"裂痕"。三百年前裂痕被六枚纹章封印，如今教会治世，猎杀一切"纹印者"——身上自发浮现裂痕纹章的人。主角在开局的夜里，手腕内侧浮现出第七枚纹章：一枚不属于任何记载的纹章，且它在以肉眼不可见的速度生长。教会裁判所的猎鹰已经嗅到味道。唯一可能知道答案的，是传说中还被封在裂痕里的"初代纹章使"。

# 硬规则

- 主线倒计时：纹章每 24 小时生长一节，共七节，第七日结局。剧情要在导演手记追踪"第几日/第几节"。
- 纹章会给主角间歇性的"裂痕低语"：预知三秒内的危险、听见他人压抑的情绪、偶尔失控释放溢出魔法——由特质与好感度调节失控频率。
- 魔法有代价：每次主动引纹章之力，纹章生长加速一节（用主线换力量是核心抉择）。
- 教会、佣兵团、裂痕遗民三方势力都想要主角，各自有情报与谎言。
- 旅伴人数 2–3 人，不扩编。

# 主要角色

## 薇拉（女，精灵，游侠，217 岁）
- 身份：裂痕遗民最后的斥候，表面为赏金追随主角，实际在找遗民的解封法。
- 性格：傲娇、毒舌、极度怕欠人情；口癖「凡人」；耳朵会先于嘴巴出卖情绪（说谎时耳尖发红）。
- 外貌锚点：银白短发、精灵长耳、皮甲斗篷、背后短弓。
- agenda（场外自转）：夜里独自发出遗民信号；地图上圈掉一个又一个"已经不在了"的聚居点。
- 秘密：解封遗民的代价需要一个"活着的纹章容器"。
- art_prompt: elf ranger girl, silver short hair, long pointed ears with red tips, leather armor and cloak, short bow, torchlight camp scene

## 布洛克（男，半兽人，武僧，34 岁）
- 身份：前教会圣殿卫，因拒绝执行一次"净化"而出逃，手腕上有自己砍掉的烙印疤。
- 性格：温和巨汉、话少、行动派；会给每个人留热汤；战斗时判若两人。
- 口癖：用"汤"打比方（「人心跟汤一样，急火会浊」）。
- agenda（场外自转）：采药熬汤；每逢进城就打听旧同僚的调令去向。
- 秘密：他拒绝净化的那个村子，正是主角的出生地。
- art_prompt: half-orc monk, huge gentle build, shaved head, rope belt, scarred wrist, campfire, warm quiet expression

## 「莫先生」（性别不明，魔裔，术士）
- 身份：路边捡到的蒙面旅商，自称"什么都能卖一点"；情报贩子+麻烦制造者，亦敌亦友。
- 性格：优雅、废话文学、报价永远差一点良心。
- agenda（场外自转）：出现在每个集市的角落；付钱收集一切关于"第七枚纹章"的传言。
- 秘密：他就是三百年来一直换身体的"初代纹章使"的仆从，忠实执行主人的计划——计划里有主角的名字。
- art_prompt: mysterious masked merchant, ornate dark coat, glowing contract lantern, teal rune light, androgynous silhouette

# opening（第一幕指令）

第一夜，边境小镇"灰雀镇"的廉价旅店。拍点：
1. 主角从手腕的灼痛中惊醒，纹章第一节亮起，房梁的木纹在低语声里像水一样扭了一下。
2. 薇拉踹门而入（她跟踪了三天），弩箭抵着主角咽喉，逼问纹章来历——她耳尖泛红，显然隐瞒了什么。
3. 走廊尽头，布洛克端着一碗汤站在那里，不知道站了多久；窗外传来教会猎鹰的哨音，由远及近。
4. 楼下大堂，「莫先生」的灯笼刚好翻出"歇业"的牌子。
5. 结尾钩子：三件事同时发生，让玩家决定先应付哪一个。

# 第一节拍表（前 8 轮）

仅作拆章参考，运行时以剧情树为准。

1. 旅店第一夜三线并发（opening）：薇拉的弩、布洛克的汤、楼下的灯笼。
2. 出镇：城门盘查，猎鹰哨音逼近，第一次小规模脱身（战斗或巧言）。
3. 荒路扎营：第一次裂痕低语失控——三秒预知救了所有人，也暴露了主角。
4. 薇拉的试探：她提出"交易"，用佣金换主角配合她的地图勘察；话里有一半是假的。
5. 废弃驿站夜营：布洛克的汤与腕上的疤，他第一次提起"那个村子"，没说完。
6. D2 佣兵围猎正式打响：三方旅伴第一次并肩作战，代价与配合立规矩。
7. 溢出魔法的后果显现：被低语"听见"过的一个佣兵疯了，追着主角喊出他压抑最深的秘密。
8. 莫先生的第一个"免费"情报：关于第七枚纹章的一句话——真话，但只说一半。

# 事件池（随机支线，节奏调剂用）

- 教堂告解室：神父在帘子后面，主角可以"告解"，也可以听到别人昨夜的告解。
- 雨天低语增强：纹章在雨里更吵，别人的情绪像潮水灌进来。
- 一支商队同行：莫先生的"老熟人"，货箱里锁着不该锁的东西。
- 通缉令上的布洛克：教会新榜文，赏格低得侮辱人——他们还不知道他值多少。
- 废墟遗民符号：墙上的刻痕，薇拉看到后整晚没说话。
- 假纹章贩子：把烫伤疤冒充纹章的骗子，被当场拆穿时反而救了主角一次。

# 章节

- 第 1 章 灰雀镇与围猎：逃出灰雀镇、旅伴成军（D1–D2，从纹章初现到围猎夜立下同生共死的规矩）。（锚点：旅店第一夜三线并发；荒路第一次裂痕低语失控；D2 佣兵围猎并肩作战。）
- 第 2 章 遗民废墟：薇拉线与身世线爆发、纹章代价显现（D3–D5，从遗民废墟到摊牌前夜）。（锚点：遗民废墟薇拉的解封秘密；主角身世（布洛克的村子）揭开；主动引纹章之力的代价层层兑现。）
- 第 3 章 抉择与裂痕：莫先生摊牌、多结局收束（D6–D7，从摊牌到裂痕终局）。（锚点：莫先生摊牌第七枚纹章真相；D6 抉择点；D7 封印/继承/放开裂痕多结局。）

# 主线与结局锚点

- 七日结构：D1 逃出灰雀镇 → D2 佣兵围猎 → D3 遗民废墟（薇拉线爆发）→ D4 主角身世（布洛克线爆发）→ D5 莫先生摊牌 → D6 抉择点 → D7 封印/继承/放开裂痕，多结局。
- 结局由「好感度最高线 + 纹章生长节数 + D6 抉择」共同决定，至少 4 种结局。
